# Zakura

协同提升 Agent 的智能。

长期项目可以把交付目标拆成有依赖、预算和验收检查的 Agent 任务，并保留恢复与人工审核记录。
参阅[执行器配置与使用](./apps/server/docs/PROJECT_EXECUTION.md)和[项目工作台](./apps/server/docs/PROJECT_WORKBENCH.md)，了解蓝图、知识协作、公平调度、代码分析、交付包与实验活动。
